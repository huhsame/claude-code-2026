# 챕터 3. 클로드 코드 기본 사용법

> 이 챕터에서는 VS Code 터미널에서 클로드 코드를 실행하고, 기본적인 명령어를 익힙니다.
> 클로드 코드와 대화하는 방법의 기초를 다지는 단계입니다.

---

## 3-1. 터미널 기초

### 터미널이란?

터미널은 컴퓨터에게 **텍스트로 명령을 내리는 창**입니다.
마우스로 클릭하는 대신, 키보드로 명령어를 입력해서 컴퓨터를 조작합니다.

클로드 코드는 이 터미널에서 실행됩니다.

---

### VS Code에서 터미널 열기

VS Code 상단 메뉴에서 터미널을 열 수 있습니다.

**방법 1: 메뉴 사용**
1. 상단 메뉴에서 `보기(View)` 클릭
2. `터미널(Terminal)` 클릭

**방법 2: 단축키 사용 (추천)**

```
Ctrl + `
```

> `` ` `` 키는 키보드 왼쪽 상단, 숫자 1 옆에 있는 백틱(`) 키입니다.

<!-- 스크린샷: VS Code에서 터미널 열린 모습 -->
![VS Code 터미널](./images/ch03-terminal-open.png)

---

### 클로드 코드 실행하기

터미널이 열렸다면, 아래 명령어를 입력하고 Enter를 누르세요.

```bash
claude
```

클로드 코드가 실행되면 아래와 같은 화면이 나타납니다.

<!-- 스크린샷: 클로드 코드 실행 화면 -->
![클로드 코드 실행](./images/ch03-claude-start.png)

> **Tip**: 명령어를 입력한 후에는 반드시 `Enter` 키를 눌러야 실행됩니다.

---

### 클로드 코드 종료하기

클로드 코드를 종료하려면 아래 명령어를 입력하세요.

```
/exit
```

또는 단축키를 사용할 수 있습니다.

```
Ctrl + C
```

<!-- 스크린샷: 클로드 코드 종료 화면 -->
![클로드 코드 종료](./images/ch03-claude-exit.png)

---

### 터미널 기본 명령어

클로드 코드를 사용하기 전에, 터미널의 기본 명령어 몇 가지를 알아두면 좋습니다.

| 명령어 | 설명 | 예시 |
|--------|------|------|
| `cd` | 폴더 이동 | `cd Desktop` (바탕화면으로 이동) |
| `cd ..` | 상위 폴더로 이동 | `cd ..` |
| `dir` | 현재 폴더의 파일 목록 보기 (Windows) | `dir` |
| `cls` | 터미널 화면 지우기 (Windows) | `cls` |

**폴더 이동 예시**

바탕화면에 `my-project`라는 폴더를 만들고 이동하려면:

```bash
cd Desktop
mkdir my-project
cd my-project
```

## 3-2. 핵심 명령어

클로드 코드에는 슬래시(`/`)로 시작하는 특별한 명령어들이 있습니다.
이 중 가장 중요한 두 가지를 알아봅니다.

---

### /init - 프로젝트 분석

`/init` 명령어는 **CLAUDE.md 파일을 생성**합니다.

클로드가 프로젝트의 코드를 분석해서, "이 프로젝트가 무엇인지" 정리한 파일을 만들어줍니다.
이 파일이 있으면 클로드가 프로젝트의 맥락을 이해하고, 더 정확한 답변을 제공합니다.

**사용 방법**

클로드 코드 실행 후 아래 명령어를 입력하세요.

```
/init
```

<!-- 스크린샷: /init 실행 후 CLAUDE.md 생성된 모습 -->
![/init 실행](./images/ch03-init-command.png)

**CLAUDE.md 파일 예시**

```markdown
# 프로젝트 개요
이 프로젝트는 개인 가계부 웹 애플리케이션입니다.

# 기술 스택
- React
- Supabase

# 주요 기능
- 수입/지출 입력
- 월별 합계 조회
- 카테고리별 분류
```

> **언제 사용하나요?**
> - 다른 사람의 코드를 가져와서 시작할 때
> - 예전에 작업하던 프로젝트를 다시 파악할 때
> - 코드가 어느 정도 쌓인 후 정리할 때
>
> **참고**: 빈 프로젝트에서는 분석할 코드가 없으므로, 나중에 해도 됩니다.

---

### /compact - 대화 압축

`/compact` 명령어는 **지금까지의 대화 내용을 요약**합니다.

클로드 코드는 대화가 길어지면 앞부분 내용을 잊어버릴 수 있습니다.
이때 `/compact`를 사용하면 대화 내용을 정리해서 토큰(사용량)을 절약할 수 있습니다.

**사용 방법**

```
/compact
```

<!-- 스크린샷: /compact 실행 전후 비교 -->
![/compact 실행](./images/ch03-compact-command.png)

> **언제 사용하나요?**
> - 대화가 길어졌을 때
> - "아까 말한 거 기억해?"라고 했는데 클로드가 기억 못할 때
> - Pro 플랜 한도가 걱정될 때

---

### 기타 유용한 명령어

| 명령어 | 설명 |
|--------|------|
| `/help` | 사용 가능한 명령어 목록 보기 |
| `/clear` | 대화 내역 초기화 |
| `/exit` | 클로드 코드 종료 |

**전체 명령어 확인**

```
/help
```

## 3-3. 한도 아끼는 습관

클로드 코드 Pro 플랜은 사용량 한도가 있습니다.
효율적으로 사용하는 습관을 들이면 한도 걱정 없이 개발할 수 있습니다.

---

### 습관 1: 요청 전에 생각 먼저 정리하기

클로드에게 무작정 말하기 전에, 내가 원하는 것을 먼저 정리하세요.

| 나쁜 예 | 좋은 예 |
|---------|---------|
| "음... 뭔가 만들어줘" | "수입/지출을 입력할 수 있는 가계부를 만들어줘" |
| "이거 왜 안 돼?" | "버튼을 클릭해도 반응이 없어. 콘솔에 에러 메시지가 없어." |
| "다시 해줘" | "금액 입력 부분에 천 단위 콤마를 추가해줘" |

---

### 습관 2: 한 번에 여러 기능 요청하지 않기

한 번에 많은 것을 요청하면 클로드가 혼란스러워할 수 있습니다.
**하나씩 요청하고, 확인하고, 다음으로** 넘어가세요.

**나쁜 예**

```
가계부 만들어줘. 수입 지출 입력되게 하고, 월별 합계도 보여주고,
그래프도 그려주고, 카테고리별로 분류도 되게 하고,
엑셀로 내보내기도 되게 해줘.
```

**좋은 예**

```
가계부를 만들건데, 먼저 수입/지출을 입력하는 화면부터 만들어줘.
```

그 다음:

```
잘 됐어. 이제 월별 합계를 보여주는 기능을 추가해줘.
```

---

### 습관 3: /compact 주기적으로 사용하기

대화가 20~30회 이상 오갔다면 `/compact`를 사용하세요.

```
/compact
```

> **Pro 팁**: 하나의 기능이 완성될 때마다 `/compact`를 실행하는 것도 좋은 방법입니다.

## 실습: 클로드 코드 첫 대화

직접 클로드 코드를 실행하고 간단한 대화를 나눠봅시다.

### Step 1: 프로젝트 폴더 만들기

1. 바탕화면에 `practice` 폴더를 만듭니다.
2. VS Code에서 해당 폴더를 엽니다.
   - `파일(File)` → `폴더 열기(Open Folder)` → `practice` 선택

### Step 2: 터미널 열기

```
Ctrl + `
```

### Step 3: 클로드 코드 실행

```bash
claude
```

### Step 4: 인사해보기

클로드 코드가 실행되면, 간단한 인사를 해봅시다.

```
안녕, 나는 클로드 코드를 처음 사용하는 사람이야. 반가워!
```

<!-- 스크린샷: 클로드 코드와 첫 대화 -->
![첫 대화](./images/ch03-first-chat.png)

### Step 5: /init 실행해보기

```
/init
```

### Step 6: 종료하기

```
/exit
```
