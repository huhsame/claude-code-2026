# 챕터 9. 고구마마켓 만들기 (1) - 상품 목록

> 이 챕터에서는 고구마마켓 프로젝트를 시작하고, Supabase를 연결한 뒤 상품 목록 화면을 만듭니다.

---

## 9-1. 프로젝트 폴더 만들기

### 새 폴더 생성

바탕화면에 고구마마켓 프로젝트용 폴더를 만듭니다.

1. VS Code 실행
2. `파일(File)` → `폴더 열기(Open Folder)`
3. 바탕화면에서 `새 폴더` 클릭
4. 폴더 이름: `goguma-market` 입력
5. `폴더 선택` 클릭

> **폴더 이름 팁**: 영어, 소문자, 하이픈(-) 사용

---

## 9-2. Supabase 프로젝트 만들기

가계부 때와 별도로, 고구마마켓용 새 프로젝트를 만듭니다.

### Step 1: Supabase 접속

```
https://supabase.com
```

로그인 후 대시보드로 이동합니다.

### Step 2: 새 프로젝트 생성

1. **New Project** 클릭
2. 프로젝트 이름: `goguma-market`
3. 비밀번호 설정 (기억해두세요)
4. Region: `Northeast Asia (Seoul)` 선택
5. **Create new project** 클릭

프로젝트 생성까지 1~2분 정도 걸립니다.

### Step 3: 연결 정보 확인

Settings → API에서 확인:
- **Project URL**: `https://xxx.supabase.co`
- **service_role key**: `eyJ...` (긴 문자열)

---

## 9-3. MCP로 Supabase 연결

챕터 7에서 배운 Supabase MCP를 연결합니다.

### 간략한 설정

클로드 코드 설정에서 MCP 서버를 추가합니다:

```json
{
  "mcpServers": {
    "supabase": {
      "command": "npx",
      "args": ["-y", "@supabase/mcp-server"],
      "env": {
        "SUPABASE_URL": "본인 Project URL",
        "SUPABASE_SERVICE_ROLE_KEY": "본인 service_role key"
      }
    }
  }
}
```

> 자세한 방법은 챕터 7을 참고하세요.

### 클로드 코드 실행

터미널에서 클로드 코드를 실행합니다:

```bash
claude
```

Supabase MCP가 연결되면 클로드가 직접 테이블을 만들고 데이터를 조작할 수 있습니다.

---

## 9-4. 고구마마켓 요청하기

### 프롬프트 작성

클로드에게 고구마마켓을 만들어달라고 요청합니다.

```
당근마켓 클론 고구마마켓을 만들고 싶어.
Supabase MCP 연결되어 있어.
단계별로 확인하면서 진행할게. 일단 상품 목록 페이지부터 만들어줘.
```

> **팁**: 처음부터 모든 기능을 다 설명하지 않아도 됩니다.
> 클로드가 알아서 필요한 것들을 물어보거나 제안해줍니다.

### 플랜 검토

클로드가 계획을 보여줍니다:
- 어떤 기술로 만들지
- 어떤 테이블을 만들지
- 어떤 파일들을 만들지

확인하고 마음에 들면:

```
응, 진행해줘
```

수정하고 싶으면:

```
디자인은 심플하게 해줘
```

```
React 말고 다른 걸로 해줘
```

---

## 9-5. 상품 목록 화면 확인

### 실행

개발이 완료되면 실행합니다.

```
실행해줘
```

또는 새 터미널에서:

```bash
npm run dev
```

### 확인할 것

1. 상품 목록이 보이는지 (처음엔 비어있음)
2. Supabase 대시보드 → Table Editor에서 `products` 테이블 확인

### 테스트 데이터 추가

Supabase 대시보드에서 직접 데이터를 추가해봅니다:

1. Table Editor → products
2. **Insert row** 클릭
3. 테스트 상품 정보 입력
4. 웹앱 새로고침 → 상품이 보이면 성공!

### 수정 요청

마음에 안 드는 부분이 있으면:

```
상품 카드 디자인을 더 심플하게 해줘
```

```
가격에 천 단위 콤마 추가해줘
```

## 9-6. 첫 번째 커밋 + GitHub 올리기

상품 목록이 완성되었으면 Git에 저장하고 GitHub에 올립니다.

### VS Code 소스 제어 탭 열기

1. VS Code 왼쪽에서 **소스 제어** 아이콘 클릭
2. 또는 단축키: `Ctrl + Shift + G`

### 커밋 메시지 작성

상단 입력창에 커밋 메시지를 입력합니다:

```
상품 목록 페이지 + Supabase 연결
```

### 커밋하기

**커밋** 버튼을 클릭합니다.

> "모든 변경사항을 스테이지하고 커밋하시겠습니까?" → **예**

### GitHub에 게시하기

1. **GitHub에 게시** 클릭
2. GitHub 로그인 팝업 → **허용**
3. 브라우저에서 GitHub 로그인
4. "Authorize Visual Studio Code" 클릭
5. 저장소 이름 확인 (`goguma-market`)
6. **공개(Public)** 또는 **비공개(Private)** 선택
7. **게시** 클릭

### 확인

github.com에서 `goguma-market` 저장소가 생겼는지 확인합니다.
