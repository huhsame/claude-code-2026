# 챕터 9. 고구마마켓 만들기 (1) - 상품 목록

> 이 챕터에서는 고구마마켓 프로젝트를 시작하고, 상품 목록 화면을 만든 뒤 첫 번째 커밋을 합니다.

---

## 9-1. 프로젝트 폴더 만들기

### 새 폴더 생성

바탕화면에 고구마마켓 프로젝트용 폴더를 만듭니다.

1. VS Code 실행
2. `파일(File)` → `폴더 열기(Open Folder)`
3. 바탕화면에서 `새 폴더` 클릭
4. 폴더 이름: `goguma-market` 입력
5. `폴더 선택` 클릭

> **폴더 이름 팁**: 영어, 소문자, 하이픈(-) 사용
> - 좋은 예: `goguma-market`, `my-market`
> - 나쁜 예: `고구마마켓`, `Goguma Market`

### 클로드 코드 실행

터미널을 열고 클로드 코드를 실행합니다.

```bash
claude
```

---

## 9-2. 고구마마켓 요청하기

### 프롬프트 작성

클로드에게 고구마마켓을 만들어달라고 요청합니다.

```
나는 개발 초보야.
고구마마켓이라는 중고거래 웹앱을 만들고 싶어.

기능:
- 상품 목록 페이지 (메인)
- 상품 상세 페이지
- 상품 등록 페이지
- 상품 수정/삭제

각 상품에는 다음 정보가 있어:
- 상품명
- 가격
- 설명
- 이미지 (URL로)
- 판매 상태 (판매중/예약중/판매완료)

일단 상품 목록 페이지부터 만들어줘.
나중에 Supabase 연결할 거니까 그거 고려해서 만들어줘.
```

### 플랜 검토

클로드가 계획을 보여주면 확인합니다:
- 어떤 기술로 만드는지 (React, Next.js 등)
- 파일 구조가 어떻게 되는지
- 상품 목록이 포함되어 있는지

마음에 들면:
```
응, 진행해줘
```

---

## 9-3. 상품 목록 화면 만들기

### 개발 진행

클로드가 코드를 작성합니다. 권한 요청이 나오면:
- `Y` 또는 `Enter`: 허용
- `A`: 항상 허용

### 실행해서 확인

개발이 완료되면 실행해봅니다.

```
실행해줘
```

또는 새 터미널에서:

```bash
npm run dev
```

브라우저에서 `http://localhost:3000` 또는 `http://localhost:5173`으로 접속해서 확인합니다.

### 수정 요청

마음에 안 드는 부분이 있으면 수정 요청합니다.

```
상품 카드 디자인을 더 심플하게 해줘
```

```
가격에 천 단위 콤마 추가해줘
```

```
판매완료된 상품은 회색으로 표시해줘
```

## 9-4. 첫 번째 커밋 + GitHub 올리기

상품 목록이 완성되었으면 Git에 저장하고 GitHub에 올립니다.

### VS Code 소스 제어 탭 열기

1. VS Code 왼쪽에서 **소스 제어** 아이콘 클릭 (가지가 갈라지는 모양)
2. 또는 단축키: `Ctrl + Shift + G`

### 변경사항 확인

소스 제어 탭에 변경된 파일 목록이 보입니다.

### 커밋 메시지 작성

상단 입력창에 커밋 메시지를 입력합니다:

```
상품 목록 페이지 구현
```

### 커밋하기

**커밋** 버튼을 클릭합니다.

> 처음 커밋할 때 "모든 변경사항을 스테이지하고 커밋하시겠습니까?" 라고 물으면 **예**를 클릭합니다.

### GitHub에 게시하기

커밋 후 **GitHub에 게시** 버튼이 나타납니다.

1. **GitHub에 게시** 클릭
2. GitHub 로그인 팝업이 뜨면 **허용** 클릭
3. 브라우저에서 GitHub 로그인
4. "Authorize Visual Studio Code" 클릭
5. VS Code로 돌아와서 저장소 이름 확인 (`goguma-market`)
6. **공개(Public)** 또는 **비공개(Private)** 선택
7. **게시** 클릭

### 확인

GitHub 웹사이트(github.com)에 접속해서 본인 계정에 `goguma-market` 저장소가 생겼는지 확인합니다.
