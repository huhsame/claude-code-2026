# 챕터 5. 가계부 실습 - 각자 개발

> 이 챕터에서는 직접 나만의 가계부 웹앱을 만들어봅니다.
> 프롬프트 작성부터 실행까지 전 과정을 경험합니다.

---

## 5-1. 프로젝트 시작하기

### VS Code에서 새 폴더 만들기

1. VS Code 실행
2. `파일(File)` → `폴더 열기(Open Folder)`
3. 바탕화면 선택 → `새 폴더` 클릭
4. 폴더 이름: `budget` 입력
5. `폴더 선택` 클릭

<!-- 스크린샷: VS Code에서 새 폴더 만들기 -->
![새 폴더 만들기](./images/ch05-new-folder.png)

> **폴더 이름 팁**: 영어로, 공백 없이, 소문자로 만드세요.
> - 좋은 예: `budget`, `my-budget`, `budget-app`
> - 나쁜 예: `가계부`, `My Budget`, `Budget App`

### 클로드 코드 실행

터미널을 열고 클로드 코드를 실행합니다.

```powershell
claude
```

## 5-2. 나만의 가계부 요청하기

### 초보자용 프롬프트 팁

개발이 처음이라면, 프롬프트에 **초보자임을 알려주세요**.
클로드가 더 쉬운 기술 스택과 간단한 구조로 만들어줍니다.

**초보자 프롬프트 예시**

```
나는 개발을 처음 해보는 초보야.
가계부 웹앱을 만들고 싶어.
최대한 간단한 구조로, 초보자도 이해할 수 있게 만들어줘.
```

```
나는 코딩을 모르는 비개발자야.
가장 기본적인 기술로 가계부를 만들어줘.
복잡한 건 빼고 심플하게 해줘.
```

### 프롬프트 예시 모음

아래 예시 중 마음에 드는 것을 **복사해서 사용**하거나, 본인만의 버전으로 수정하세요.

**예시 1: 기본 가계부**
```
나는 개발 초보야.
간단한 가계부 웹앱을 만들어줘.
- 수입/지출 입력
- 날짜, 금액, 메모 입력
- 목록으로 보여주기
- 총 잔액 표시
```

**예시 2: 카테고리가 있는 가계부**
```
나는 개발 초보야.
카테고리별 가계부를 만들어줘.
- 수입/지출 선택
- 카테고리: 식비, 교통, 쇼핑, 문화, 기타
- 날짜, 금액, 메모 입력
- 카테고리별 합계 보여주기
```

**예시 3: 월별 가계부**
```
나는 개발 초보야.
월별로 관리하는 가계부를 만들어줘.
- 수입/지출 입력
- 월 선택 기능
- 해당 월의 내역만 보여주기
- 월별 총 수입, 총 지출, 잔액 표시
```

**예시 4: 심플 디자인 가계부**
```
나는 개발 초보야.
미니멀한 디자인의 가계부를 만들어줘.
- 흰색 배경, 검정 글씨
- 불필요한 장식 없이 깔끔하게
- 수입/지출 입력과 목록만
```

## 5-3. 플랜 모드 이해하기

### 플랜 모드란?

클로드에게 요청하면, 바로 코드를 작성하지 않고 **계획(Plan)을 먼저 보여줍니다**.

<!-- 스크린샷: 플랜 모드 화면 -->
![플랜 모드](./images/ch05-plan-mode.png)

### 플랜에서 보여주는 것들

클로드가 플랜에서 보여주는 내용:

| 항목 | 설명 |
|------|------|
| **기술 스택** | 어떤 기술로 만들지 (React, HTML/CSS 등) |
| **파일 구조** | 어떤 파일들을 만들지 |
| **기능 목록** | 어떤 기능들을 구현할지 |
| **진행 순서** | 어떤 순서로 개발할지 |

### 플랜 선택지

플랜을 보여준 후, 클로드가 물어봅니다:

```
이 계획대로 진행할까요?
```

**선택지와 대응 방법**

| 상황 | 입력할 내용 |
|------|------------|
| 플랜이 마음에 들면 | `응` 또는 `진행해줘` 또는 그냥 Enter |
| 수정하고 싶으면 | `카테고리를 5개로 줄여줘` 등 구체적으로 요청 |
| 다시 처음부터 | `다른 방식으로 다시 계획해줘` |
| 더 간단하게 | `더 간단하게 해줘. 기능을 줄여줘` |

### 플랜 수정 예시

**기술 스택 변경**
```
React 말고 그냥 HTML/CSS/JavaScript로 해줘
```

**기능 추가**
```
삭제 기능도 추가해줘
```

**기능 제거**
```
그래프는 빼줘. 너무 복잡해
```

**디자인 변경**
```
색상은 파란색 계열로 해줘
```

## 5-4. 개발 진행하기

### 개발 중 수정 요청

개발이 진행되면서 수정하고 싶은 부분이 생기면:

```
금액에 천 단위 콤마 추가해줘
```

```
버튼 크기를 더 크게 해줘
```

```
색상이 너무 진해. 더 연하게 해줘
```

### 에러가 발생하면

에러가 나면 당황하지 마세요. **에러 메시지를 클로드에게 보여주면 됩니다**.

```
에러가 났어. 이거 봐줘:
[에러 메시지 복사해서 붙여넣기]
```

클로드가 에러를 분석하고 수정해줍니다.

## 5-5. 터미널에서 실행하기

### 개발 서버 실행

개발이 완료되면 브라우저에서 확인해야 합니다.
터미널에서 아래 명령어를 입력하세요.

```powershell
npm run dev
```

<!-- 스크린샷: npm run dev 실행 -->
![npm run dev](./images/ch05-npm-run-dev.png)

실행되면 터미널에 주소가 표시됩니다:

```
Local: http://localhost:5173
```

이 주소를 `Ctrl + 클릭`하거나, 브라우저에 직접 입력해서 접속합니다.

> **참고**: 주소는 프로젝트에 따라 다를 수 있습니다.
> - `http://localhost:3000`
> - `http://localhost:5173`
> - `http://localhost:8080`

### 개발 서버 종료

개발 서버를 종료하려면 터미널에서:

```
Ctrl + C
```

종료 확인 메시지가 나오면 `Y`를 입력하거나 다시 `Ctrl + C`를 누릅니다.

<!-- 스크린샷: Ctrl+C로 서버 종료 -->
![서버 종료](./images/ch05-server-stop.png)

### 터미널 명령어 정리

| 명령어 | 설명 |
|--------|------|
| `npm run dev` | 개발 서버 실행 |
| `npm start` | 개발 서버 실행 (프로젝트에 따라 다름) |
| `Ctrl + C` | 실행 중인 프로그램 종료 |

### 서버가 이미 실행 중일 때

"Port already in use" 에러가 나면:

1. 다른 터미널에서 서버가 실행 중인지 확인
2. 실행 중인 서버를 `Ctrl + C`로 종료
3. 다시 `npm run dev` 실행

## 5-6. CLAUDE.md 확인하기

### CLAUDE.md란?

클로드가 프로젝트를 이해하기 위한 파일입니다.
개발이 완료된 후 `/init`을 실행하면 생성됩니다.

```
/init
```

### 파일 확인하기

VS Code 왼쪽 파일 탐색기에서 `CLAUDE.md` 파일을 클릭해서 열어보세요.

<!-- 스크린샷: CLAUDE.md 파일 내용 -->
![CLAUDE.md 확인](./images/ch05-claude-md.png)

파일에는 다음 내용이 포함됩니다:

- 프로젝트 개요
- 사용된 기술 스택
- 파일 구조
- 주요 기능 설명

> **참고**: 이 파일이 있으면 다음에 클로드 코드를 실행할 때 프로젝트를 바로 이해합니다.

## 5-7. 트러블슈팅

### 자주 발생하는 문제

**문제 1: npm run dev가 안 됨**

```
'npm'은(는) 내부 또는 외부 명령... 이 아닙니다
```

→ Node.js가 설치되지 않았거나 환경변수가 안 됨. 챕터 2 확인.

**문제 2: 브라우저에 아무것도 안 나옴**

→ 주소가 맞는지 확인. 터미널에 표시된 주소 그대로 입력.

**문제 3: 코드가 이상하게 됨**

```
방금 한 거 취소해줘
```

또는 클로드 코드에서 이전 대화로 돌아가기.

**문제 4: 클로드가 이상한 방향으로 감**

```
잠깐, 멈춰.
처음부터 다시 하자.
[원하는 내용 다시 설명]
```

### 에러 대처법

모든 에러는 **클로드에게 보여주면 됩니다**.

1. 에러 메시지 전체 복사
2. 클로드에게 붙여넣기
3. "이거 해결해줘" 요청
