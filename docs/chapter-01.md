# 챕터 1. 오프닝

> 바이브 코딩이 무엇인지, 클로드 코드로 무엇을 할 수 있는지 알아봅니다.
> 그리고 이 교육을 듣는 마음가짐에 대해 이야기합니다.

---

## 1-1. 바이브 코딩이란?

### 코딩의 새로운 방식

**바이브 코딩(Vibe Coding)**은 코드를 직접 작성하지 않고, AI와 대화하며 개발하는 방식입니다.

```
기존 개발: 개발자가 코드를 한 줄씩 직접 작성
바이브 코딩: AI에게 원하는 것을 말하면 AI가 코드를 작성
```

### 예시

**기존 방식**
```javascript
function add(a, b) {
  return a + b;
}
console.log(add(1, 2));
```

**바이브 코딩 방식**
```
"1과 2를 더하는 프로그램 만들어줘"
```

결과는 같습니다. 하지만 바이브 코딩은 코드를 몰라도 됩니다.

### 왜 "바이브"인가?

"바이브(Vibe)"는 "분위기", "느낌"이라는 뜻입니다.

코드의 정확한 문법을 몰라도, **내가 원하는 것의 느낌만 전달하면** AI가 알아서 만들어줍니다.

---

## 1-2. 클로드 코드란?

### AI 개발 도구

**클로드 코드(Claude Code)**는 Anthropic에서 만든 AI 개발 도구입니다.

터미널에서 AI와 대화하며 코드를 작성하고, 파일을 만들고, 프로그램을 실행할 수 있습니다.

### 클로드 코드로 할 수 있는 것

| 할 수 있는 것 | 예시 |
|--------------|------|
| **웹사이트 만들기** | 포트폴리오, 블로그, 쇼핑몰 |
| **웹앱 만들기** | 가계부, 할일 목록, 메모장 |
| **게임 만들기** | 테트리스, 틱택토, 퀴즈 게임 |
| **자동화 도구** | 엑셀 데이터 처리, 파일 정리 |
| **AI 서비스** | 챗봇, 이미지 생성기, 번역기 |

### 에이전트란?

클로드 코드는 단순히 코드만 작성하는 게 아닙니다.

**에이전트(Agent)**로서 스스로 판단하고, 파일을 읽고, 명령어를 실행하고, 문제를 해결합니다.

```
일반 AI: "이런 코드를 작성하면 됩니다" (답변만 함)
에이전트: 직접 파일을 만들고, 코드를 작성하고, 실행까지 함
```

여러분은 **지시만 하면** 됩니다. 클로드가 알아서 실행합니다.

## 1-3. 이 교육에서 만드는 것들

### 가계부 웹앱

수입과 지출을 기록하는 웹앱을 만듭니다.
데이터베이스에 연결해서 새로고침해도 데이터가 유지되게 합니다.

### 고구마마켓 클론

중고거래 서비스를 만들어봅니다.
Git으로 버전 관리하고, 팀원들과 협업하는 방법을 배웁니다.

### AI 챗봇

Gemini API를 연결해서 AI 챗봇을 만듭니다.
파일을 업로드하면 그 내용을 기반으로 답변하는 똑똑한 챗봇까지 만들어봅니다.

### 그 외

시간이 남으면 이미지 생성기, 퀴즈 게임 등 자유롭게 만들어봅니다.

## 1-4. 마음가짐

### 모르는 용어가 많이 나옵니다

API, DB, Git, 터미널, 컴포넌트, 서버, 클라이언트...

**다 몰라도 됩니다.**

지금 당장 이해할 필요 없습니다. 일단 따라하다 보면 자연스럽게 감이 옵니다.

### 한 단계씩 완벽하게 배우는 게 아닙니다

전통적인 개발 교육은 이렇습니다:
1. HTML을 배운다
2. CSS를 배운다
3. JavaScript를 배운다
4. 그 다음에야 뭔가 만든다

**바이브 코딩은 다릅니다.**

1. 일단 만든다
2. 만들면서 필요한 것을 배운다
3. 완벽하지 않아도 동작하면 OK

### 얼기설기 완성품을 만드는 게 목표입니다

코드가 예쁜지, 구조가 좋은지는 신경 쓰지 마세요.

**동작하면 됩니다.**

나중에 필요하면 다듬으면 됩니다. AI한테 "이거 더 좋게 바꿔줘"라고 하면 됩니다.

### 개발자가 되려는 게 아닙니다

이 교육의 목표는 **개발자가 되는 것이 아닙니다.**

**AI를 잘 활용하는 사람**이 되는 것입니다.

| 개발자 | AI 활용자 |
|--------|----------|
| 코드를 직접 작성 | AI에게 지시 |
| 문법을 암기 | 원하는 것을 설명 |
| 에러를 직접 디버깅 | AI에게 에러 해결 요청 |
| 몇 달~몇 년 학습 | 며칠이면 뭔가 만듦 |

여러분은 **AI를 잘 부리는 사람**이 되면 됩니다.

### 에러가 나면?

에러는 무조건 납니다. 개발자도 매일 에러를 만납니다.

당황하지 마세요. **에러 메시지를 클로드한테 보여주면** 클로드가 해결해줍니다.

```
"에러 났어. 이거 봐줘: [에러 메시지 붙여넣기]"
```

이게 끝입니다.

### 질문은 언제든지

막히면 바로 질문하세요. 혼자 끙끙대지 마세요.

- 강사에게 질문
- 옆 사람에게 질문
- **클로드에게 질문** ← 이것도 됩니다!

```
"이게 뭔 뜻이야?"
"왜 이렇게 해야 해?"
"다른 방법은 없어?"
```

클로드는 친절하게 설명해줍니다.

## 1-5. 시연: 테트리스 게임

> 이 섹션은 강사가 직접 시연합니다.

클로드 코드에게 "테트리스 게임 만들어줘"라고 요청합니다.

1~2분 만에 실제로 플레이할 수 있는 테트리스 게임이 완성됩니다.

**이게 바이브 코딩입니다.**
