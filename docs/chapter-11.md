# 챕터 11. 고구마마켓 만들기 (3) - 수정/삭제

> 이 챕터에서는 상품 수정/삭제 기능을 완성하고 CRUD를 마무리합니다.

---

## 11-1. 상품 수정 기능

### 클로드에게 요청

```
상품 상세 페이지에 수정 버튼을 추가해줘.

수정 버튼을 누르면:
- 수정 페이지로 이동
- 기존 정보가 입력되어 있음
- 수정 후 저장하면 Supabase에 반영됨
```

### 확인

1. 상세 페이지에서 수정 버튼 확인
2. 수정 페이지에서 기존 정보 확인
3. 정보 수정 후 저장
4. Supabase 대시보드에서도 변경 확인

## 11-3. 상품 삭제 기능

### 클로드에게 요청

```
상품 상세 페이지에 삭제 버튼을 추가해줘.

삭제 버튼을 누르면:
- "정말 삭제하시겠습니까?" 확인 메시지
- 확인하면 Supabase에서 삭제되고 목록으로 이동
```

### 확인

1. 상세 페이지에서 삭제 버튼 확인
2. 삭제 버튼 클릭 → 확인 메시지
3. 확인 후 목록에서 사라졌는지 확인
4. Supabase 대시보드에서도 삭제 확인
