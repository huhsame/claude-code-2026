# 챕터 11. 고구마마켓 만들기 (3) - 수정/삭제

> 이 챕터에서는 상품 수정/삭제 기능을 완성하고 CRUD를 마무리합니다.

---

## 11-1. 상품 수정 기능

### 클로드에게 요청

```
상품 수정 기능 추가해줘
```

클로드가 수정 버튼과 수정 페이지를 만들어줍니다.

### 확인

1. 상세 페이지에서 수정 버튼 확인
2. 수정 페이지에서 기존 정보가 채워져 있는지 확인
3. 정보 수정 후 저장
4. Supabase 대시보드에서도 변경 확인

### 수정 요청 (필요시)

```
수정 완료되면 상세 페이지로 돌아가게 해줘
```

### 커밋 메시지


### 커밋 + 푸시

소스 제어 탭에서 커밋하고 푸시합니다.

---

## 11-3. 상품 삭제 기능

### 클로드에게 요청

```
상품 삭제 기능 추가해줘
```

클로드가 삭제 버튼과 확인 메시지를 만들어줍니다.

### 확인

1. 상세 페이지에서 삭제 버튼 확인
2. 삭제 버튼 클릭 → 확인 메시지
3. 확인 후 목록에서 사라졌는지 확인
4. Supabase 대시보드에서도 삭제 확인
