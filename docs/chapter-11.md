---

## 11-1. 상품 수정 기능

### 클로드에게 요청

```
상품 상세 페이지에 수정 버튼을 추가해줘.

수정 버튼을 누르면:
- 수정 페이지로 이동
- 기존 정보가 입력되어 있음
- 수정 후 저장하면 반영됨
```

### 확인

1. 상세 페이지에서 수정 버튼 확인
2. 수정 페이지에서 기존 정보 확인
3. 정보 수정 후 저장
4. 변경사항 반영 확인

## 11-5. Supabase 연결하기

지금까지는 새로고침하면 데이터가 사라집니다.
Supabase에 연결해서 데이터를 저장합니다.

### 사전 준비

챕터 6에서 만든 Supabase 프로젝트를 사용합니다.
새 프로젝트를 만들어도 됩니다.

### 테이블 만들기

Supabase 대시보드에서 `products` 테이블을 만듭니다.

```
테이블 이름: products

컬럼:
- id (int8, Primary Key, 자동생성)
- created_at (timestamp, 자동생성)
- name (text) - 상품명
- price (int8) - 가격
- description (text) - 설명
- image_url (text) - 이미지 URL
- status (text) - 판매상태
```

### 클로드에게 연결 요청

```
Supabase에 연결해줘.

프로젝트 URL: [본인 Supabase URL]
API Key: [본인 anon key]

products 테이블과 연결해서:
- 목록: 테이블에서 불러오기
- 등록: 테이블에 추가
- 수정: 테이블 업데이트
- 삭제: 테이블에서 삭제
```

> **URL과 Key 찾기**: Supabase 대시보드 → Settings → API

### 확인

1. 상품 등록 → 새로고침 → 데이터 유지되는지 확인
2. Supabase 대시보드 → Table Editor에서 데이터 확인
