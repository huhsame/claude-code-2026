# 챕터 10. 고구마마켓 만들기 (2) - 상세/등록

> 이 챕터에서는 상품 상세 페이지와 등록 기능을 추가하고, 각 기능마다 커밋합니다.

---

## 10-1. 상품 상세 페이지 추가

### 클로드에게 요청

```
상품을 클릭하면 상세 페이지로 이동하게 해줘.

상세 페이지에는:
- 상품 이미지 (크게)
- 상품명
- 가격
- 판매 상태
- 상세 설명
- 목록으로 돌아가기 버튼
```

### 확인

개발이 완료되면 실행해서 확인합니다.

```
실행해줘
```

상품 목록에서 상품을 클릭해보고, 상세 페이지로 잘 이동하는지 확인합니다.

---

## 10-2. 두 번째 커밋

상세 페이지가 완성되면 커밋합니다.

### 소스 제어 탭 열기

`Ctrl + Shift + G`

### 커밋 메시지 작성

```
상품 상세 페이지 추가
```

### 커밋 + 푸시

1. **커밋** 버튼 클릭
2. **변경 내용 동기화** (또는 **푸시**) 버튼 클릭

> GitHub에 올리는 것을 **푸시(Push)**라고 합니다.

---

## 10-3. 상품 등록 폼 추가

### 클로드에게 요청

```
상품 등록 페이지를 만들어줘.

입력 항목:
- 상품명 (필수)
- 가격 (필수, 숫자만)
- 설명
- 이미지 URL
- 판매 상태 (판매중/예약중/판매완료 선택)

등록 버튼을 누르면 목록에 추가되고 메인으로 돌아가게 해줘.
```

### 확인

1. 메인 페이지에서 "상품 등록" 버튼 확인
2. 등록 페이지에서 정보 입력
3. 등록 버튼 클릭
4. 목록에 새 상품이 추가되었는지 확인

### 수정 요청 (필요시)

```
가격 입력할 때 숫자만 입력되게 해줘
```

```
필수 항목 안 채우면 등록 버튼 비활성화해줘
```

---

## 10-4. 세 번째 커밋

### 커밋 메시지

```
상품 등록 기능 추가
```

### 커밋 + 푸시

1. 소스 제어 탭에서 커밋
2. 푸시

---

## 10-5. 커밋 히스토리 확인

지금까지 3번 커밋했습니다. 히스토리를 확인해봅시다.

### 방법 1: 터미널에서

클로드 코드를 잠시 종료하고:

```bash
git log --oneline
```

결과 예시:
```
a1b2c3d 상품 등록 기능 추가
e4f5g6h 상품 상세 페이지 추가
i7j8k9l 상품 목록 페이지 구현
```

### 방법 2: VS Code에서

소스 제어 탭 → 상단의 **...** 메뉴 → **커밋 보기**

### 방법 3: GitHub에서

1. github.com 접속
2. 본인 계정 → `goguma-market` 저장소
3. **Commits** 클릭

커밋 메시지들이 시간순으로 보입니다.
