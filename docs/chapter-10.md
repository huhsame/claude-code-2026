# 챕터 10. 고구마마켓 만들기 (2) - 상세/등록

> 이 챕터에서는 상품 상세 페이지와 등록 기능을 추가하고, 각 기능마다 커밋합니다.

---

## 10-1. 상품 상세 페이지 추가

### 클로드에게 요청

```
상품 클릭하면 상세 페이지로 가게 해줘
```

클로드가 알아서 상세 페이지를 만들어줍니다.

### 확인

개발이 완료되면 실행해서 확인합니다.

```
실행해줘
```

상품 목록에서 상품을 클릭해보고, 상세 페이지로 잘 이동하는지 확인합니다.

### 수정 요청 (필요시)

```
뒤로가기 버튼 추가해줘
```

```
이미지 더 크게 보여줘
```

---

## 10-2. 두 번째 커밋

상세 페이지가 완성되면 커밋합니다.

### 소스 제어 탭 열기

`Ctrl + Shift + G`

### 커밋 메시지 작성

```
상품 상세 페이지 추가
```

### 커밋 + 푸시

1. **커밋** 버튼 클릭
2. **변경 내용 동기화** (또는 **푸시**) 버튼 클릭

---

## 10-3. 상품 등록 기능 추가

### 클로드에게 요청

```
상품 등록 기능 추가해줘
```

클로드가 등록 페이지와 폼을 만들어줍니다.

### 확인

1. 메인 페이지에서 "상품 등록" 버튼 확인
2. 등록 페이지에서 정보 입력
3. 등록 버튼 클릭
4. 목록에 새 상품이 추가되었는지 확인
5. Supabase 대시보드에서도 데이터 확인

### 수정 요청 (필요시)

```
가격은 숫자만 입력되게 해줘
```

```
필수 항목 표시해줘
```

---

## 10-4. 세 번째 커밋

### 커밋 메시지

```
상품 등록 기능 추가
```

### 커밋 + 푸시

---

## 10-5. 커밋 히스토리 확인

지금까지 3번 커밋했습니다. 히스토리를 확인해봅시다.

### 방법 1: 클로드에게 물어보기

```
지금까지 커밋 내역 보여줘
```

### 방법 2: VS Code에서

소스 제어 탭 → 상단의 **...** 메뉴 → **커밋 보기**

### 방법 3: GitHub에서

1. github.com 접속
2. 본인 계정 → `goguma-market` 저장소
3. **Commits** 클릭
