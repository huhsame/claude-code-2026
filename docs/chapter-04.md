# 챕터 4. 가계부 실습 - 시연

> 이 챕터에서는 강사가 클로드 코드로 가계부 웹앱을 만드는 과정을 시연합니다.
> Plan 모드, 프롬프트 작성법, Edit 모드를 배웁니다.

---

## 4-1. 프로젝트 시작

### 새 폴더 만들기

바탕화면에 가계부 프로젝트용 폴더를 만듭니다.

```bash
cd Desktop
mkdir my-budget
cd my-budget
```

### VS Code에서 폴더 열기

1. VS Code 실행
2. `파일(File)` → `폴더 열기(Open Folder)`
3. 방금 만든 `my-budget` 폴더 선택

### 클로드 코드 실행

터미널을 열고 클로드 코드를 실행합니다.

```bash
claude
```

## 4-2. Plan 모드와 프롬프트 작성법

### Plan 모드란?

클로드 코드에게 무언가를 요청하면, 바로 코드를 작성하지 않고 **먼저 계획(Plan)을 보여줍니다**.

이 계획을 검토하고, 수정하고, 승인하는 과정이 바이브 코딩의 핵심입니다.

### 가계부 요청하기

클로드에게 가계부를 만들어달라고 요청합니다.

```
가계부 웹앱을 만들어줘.
- 수입/지출을 입력할 수 있어야 해
- 날짜, 금액, 카테고리, 메모를 입력받아
- 입력한 내역이 목록으로 보여야 해
- 총 수입, 총 지출, 잔액을 보여줘
```

### 플랜 검토하기

클로드가 계획을 보여줍니다. 이때 확인할 것들:

- **전체 구조가 맞는지**: 어떤 파일들을 만들 건지
- **기능이 빠지지 않았는지**: 내가 요청한 것들이 다 포함되었는지
- **이상한 부분은 없는지**: 불필요한 기능이 포함되지 않았는지

### 플랜 수정 요청하기

플랜에서 수정하고 싶은 부분이 있다면:

```
카테고리는 식비, 교통비, 문화생활, 기타로 고정해줘
```

```
디자인은 심플하게 해줘. 색상은 파란색 계열로
```

### 플랜 승인하기

플랜이 마음에 들면 승인합니다. 클로드가 물어보면:

```
응, 진행해줘
```

또는 그냥 Enter를 누르면 됩니다.

## 4-3. 좋은 프롬프트 vs 나쁜 프롬프트

바이브 코딩에서 **프롬프트 품질이 결과물 품질을 결정**합니다.

### 나쁜 프롬프트

```
가계부 만들어줘
```

**문제점:**
- 어떤 기능이 필요한지 모름
- 클로드가 임의로 결정해버림
- 원하는 결과가 안 나올 확률 높음

### 좋은 프롬프트

```
가계부 웹앱을 만들어줘.
- 수입/지출을 입력할 수 있어야 해
- 날짜, 금액, 카테고리, 메모를 입력받아
- 입력한 내역이 목록으로 보여야 해
- 총 수입, 총 지출, 잔액을 보여줘
```

**좋은 점:**
- 필요한 기능이 명확함
- 입력 항목이 구체적임
- 원하는 결과를 얻을 확률 높음

### 프롬프트 작성 팁

| 나쁜 예 | 좋은 예 |
|---------|---------|
| 가계부 만들어줘 | 수입/지출 입력, 목록 표시, 잔액 계산이 되는 가계부 만들어줘 |
| 예쁘게 해줘 | 파란색 계열로 심플하게 디자인해줘 |
| 이상해, 고쳐줘 | 금액 입력할 때 숫자만 입력되게 해줘 |
| 더 좋게 해줘 | 금액에 천 단위 콤마를 추가해줘 |

### 핵심 원칙

1. **구체적으로**: 무엇을, 어떻게 원하는지 명확하게
2. **항목별로**: 여러 기능은 목록으로 나눠서
3. **한 번에 하나씩**: 너무 많은 것을 한 번에 요청하지 않기

## 4-4. Edit 모드와 대화 관리

### 부분 수정 요청하기

가계부가 만들어졌는데 수정하고 싶은 부분이 있다면, 구체적으로 요청합니다.

**금액 표시 수정**
```
금액에 천 단위 콤마를 추가해줘
```

**색상 변경**
```
헤더 배경색을 남색(#1a237e)으로 바꿔줘
```

**기능 추가**
```
삭제 버튼을 추가해서 내역을 삭제할 수 있게 해줘
```

### 이전 상태로 돌아가기

클로드가 수정한 결과가 마음에 안 들 때, 이전 상태로 돌아갈 수 있습니다.

**방법 1: Undo 요청**
```
방금 한 거 취소해줘
```

**방법 2: 대화창에서 되돌리기**

클로드 코드 화면에서 이전 대화로 돌아가서 다시 시작할 수 있습니다.

### 잘못된 방향으로 갔을 때

개발이 이상한 방향으로 갔다면:

```
잠깐, 이건 내가 원한 게 아니야.
원래 요청으로 돌아가서 다시 해줘.
내가 원한 건 [원하는 내용]이야.
```

## 4-5. 완성 및 확인

### 로컬에서 실행하기

클로드가 개발을 완료하면, 실행 방법을 알려줍니다.

보통 아래와 같은 명령어로 실행합니다:

```bash
npm run dev
```

또는

```bash
npm start
```

### 브라우저에서 확인하기

터미널에 표시된 주소로 접속합니다. 보통 `http://localhost:3000` 또는 `http://localhost:5173` 입니다.

### 테스트하기

1. 수입 항목 추가해보기
2. 지출 항목 추가해보기
3. 총 수입, 총 지출, 잔액이 맞는지 확인
4. 삭제 기능 테스트
