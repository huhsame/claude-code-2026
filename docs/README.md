# 클로드 코드 교육 교재

> 비개발자를 위한 바이브 코딩 입문

---

## 바이브 코딩이란?

**바이브 코딩(Vibe Coding)**은 코드를 직접 작성하지 않고, AI와 대화하며 개발하는 방식입니다.

- 프로그래밍 언어를 몰라도 됩니다
- 자연어(한국어)로 원하는 것을 설명합니다
- AI가 코드를 작성해줍니다
- 결과를 확인하고 수정을 요청합니다

---

## 클로드 코드란?

**클로드 코드(Claude Code)**는 Anthropic에서 만든 AI 개발 도구입니다.

터미널에서 AI와 대화하며 코드를 작성하고, 파일을 만들고, 프로그램을 실행할 수 있습니다.

클로드 코드는 **에이전트(Agent)**로서 스스로 판단하고, 파일을 읽고, 명령어를 실행하고, 문제를 해결합니다. 여러분은 지시만 하면 됩니다.

---

## 이 교재에서 만드는 것

| 프로젝트 | 배우는 것 |
|---------|----------|
| **가계부** | 클로드 코드 사용법, Supabase 데이터베이스 |
| **고구마마켓** | Git/GitHub 협업, Vercel 배포 |
| **AI 챗봇** | API 연동, 파일 업로드, 이미지 생성 |

---

## 마음가짐

- **모르는 용어가 많이 나옵니다** - 다 몰라도 됩니다. 따라하다 보면 감이 옵니다.
- **완벽하지 않아도 OK** - 동작하면 됩니다. 나중에 AI한테 다듬어달라고 하면 됩니다.
- **에러가 나면?** - 에러 메시지를 클로드한테 보여주면 해결해줍니다.
