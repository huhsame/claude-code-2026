# 클로드 코드 교육 교재

> 비개발자를 위한 바이브 코딩 입문

---

## 바이브 코딩이란?

**코드를 모르는 사람도 AI와 대화하며 개발할 수 있는 새로운 방식**입니다.

- 프로그래밍 언어를 몰라도 됩니다
- 자연어(한국어)로 원하는 것을 설명합니다
- AI가 코드를 작성해줍니다
- 결과를 확인하고 수정을 요청합니다

---

## 이 교재에서 배우는 것

| 단계 | 내용 |
|------|------|
| **기초** | 클로드 코드 설치, 터미널 사용법, 기본 명령어 |
| **웹앱 개발** | 가계부 웹앱 만들기, Supabase DB 연결 |
| **협업** | Git/GitHub으로 버전 관리, 브랜치 작업 |
| **배포** | Vercel로 인터넷에 공개 |
| **API 연동** | Gemini API로 챗봇 만들기 |
| **심화** | 파일 기반 챗봇, 이미지 생성기, 스킬/에이전트 |
