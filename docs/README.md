# 클로드 코드 교육 교재

> 비개발자를 위한 바이브 코딩 입문

---

## 바이브 코딩이란?

**코드를 모르는 사람도 AI와 대화하며 개발할 수 있는 새로운 방식**입니다.

- 프로그래밍 언어를 몰라도 됩니다
- 자연어(한국어)로 원하는 것을 설명합니다
- AI가 코드를 작성해줍니다
- 결과를 확인하고 수정을 요청합니다

---

## 이 교재에서 배우는 것

바이브 코딩으로 **가계부**, **당근마켓 클론**, **AI 챗봇**을 직접 만들어봅니다.

개발하면서 **에이전트**와 **스킬**을 비롯한 클로드 코드의 최신 기능들을 익히고, **데이터베이스 연결**, **Git/GitHub**, **배포**까지 실제 서비스 개발의 전 과정을 경험합니다.

| 단계 | 만드는 것 | 배우는 것 |
|------|----------|----------|
| **기초** | 가계부 웹앱 | 클로드 코드 사용법, 프롬프트 작성법 |
| **DB 연결** | 가계부 + Supabase | 데이터베이스, MCP |
| **협업** | 당근마켓 클론 | Git, GitHub, 브랜치 |
| **배포** | 당근마켓 배포 | Vercel |
| **API 연동** | AI 챗봇 | Gemini API, 최신 문서 활용법 |
| **심화** | 파일 기반 챗봇, 이미지 생성기 | 스킬, 에이전트 |
